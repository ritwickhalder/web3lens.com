# Web3Lens — Blockchain Search Engine

Website: https://www.web3lens.com/ · Developer: Ritwick Halder (https://www.ritwick.com)

Search any of 769 blockchains for an address, transaction hash, block or data, plus a crypto directory
and a beginner's guide. Built with Next.js 16 (App Router), React 19, TypeScript and Tailwind v4;
hosted on Vercel.

- What the site does: [FEATURES.md](FEATURES.md)
- What's next: [ROADMAP.md](ROADMAP.md)

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # explorer parity with the legacy site, explorer, auto-detect and contact unit tests
npm run lint
npm run typecheck
npm run build
```

## Layout

| Path | What |
|---|---|
| `app/` | Routes (one folder per page), `api/contact`, sitemap/robots/OG image |
| `components/` | UI: `layout/` (header, footer), `brand/` (logo), `search/` (smart search, chain picker), `home/` (popular chains, examples), `directory/`, `guide/`, `contact/`, `content/`, `ui/` |
| `config/site.ts` | Brand, canonical URL, nav and news links, donation addresses |
| `data/chains.json` | Chain → explorer routing (generated by `npm run chains:convert`) |
| `data/directory.json` | Directory entries |
| `content/guide.ts` | Beginner's guide FAQ |
| `lib/` | `chains.ts`, `explorer.ts`, `detect.ts` (auto-detect), `recent.ts`, `chain-meta.ts`, `contact.ts`, `metadata.ts` |
| `scripts/` | Legacy converter and tests (`scripts/test/*.test.ts`, run with `node:test` via tsx) |
| `legacy/` | The pre-Next.js static site, kept for comparison until parity is confirmed |

## Deploy (Vercel)

Environment variables (see `.env.example`):

- `NEXT_PUBLIC_GA_ID` — GA4 measurement id (optional)
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `CONTACT_NOTIFY_TO` —
  contact form email. Without `SMTP_USER`/`SMTP_PASSWORD` the form still validates but sends nothing.

Add both `web3lens.com` and `www.web3lens.com` to the project; the app redirects the apex domain to `www`.
